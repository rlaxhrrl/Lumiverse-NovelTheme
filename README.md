# Novel Theme (Lumiverse)

루미버스 채팅 화면을 심플한 소설형으로 바꾸는 확장이에요. 다크·라이트 테마 둘 다 루미버스 테마 색을 그대로 따라가요.
확장을 끄면 원래 화면으로 바로 돌아가요.

## 바뀌는 것

- **본문**: 말풍선 없이 한 줄로 이어지고, 메시지 사이는 얇은 구분선. 내 메시지도 왼쪽. 글자 16px, 넓은 줄 간격.
- **메시지 도구**: 복사 · 수정 · 분기 · ⋯ · 삭제(빨강)가 항상 같은 자리에 있어요. 숨기기 · 앵커 · 프롬프트 통계는 ⋯ 메뉴 안에 있어요. 번호·시간·토큰은 메시지를 누르거나 마우스를 올리면 보여요.
- **위쪽**: 둥근 뒤로가기 버튼, 캐릭터 이름, 반투명 버튼 묶음.
- **아래 입력 패널**
  - `＋` 메뉴: 이어쓰기(덧붙이기) · 대사 대신 쓰기 · 빠른 답장 · 가이드 생성 · 페르소나 애드온 · 파일 첨부 · 음성 입력 · 도구 · 더보기 · 버튼 설정
  - 입력칸이 비어 있으면 **▶ 이어서**: 캐릭터가 새 메시지로 이어서 씀. 글을 쓰면 보내기 버튼.
  - `[다시 생성 | ✱ | 프리셋 옵션]` · 👤 페르소나 · 모델 이름 ⇄
  - `✱`: 입력칸에 `*` 하나 넣기
- **긴 상태창**: 200px 넘는 상태창은 접혀 있고 "펼치기"로 열어요. (버튼이 있는 패널은 그대로)

모든 버튼은 루미버스 원래 버튼을 눌러 주는 방식이라 기능은 그대로예요.

## 설치

루미버스 → Extensions → 깃허브 주소로 설치: `https://github.com/rlaxhrrl/Lumiverse-NovelTheme`

## 개발

```sh
bun install
bun run build   # dist/frontend.js (확장), dist/preview.js (페이지에 임시로 입혀 보기)
```
